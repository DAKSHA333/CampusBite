# CampusBite visual assets

All seven assets are bundled under `src/main/resources/images/` and packaged inside the executable JAR. The application never fetches images at runtime. Photographs are serving suggestions, not photographs of this classroom canteen's actual products. Images retain their original content; the UI scales and crops them to fit each component.

## CampusBite logo

File: `src/main/resources/images/brand/campusbite-logo.png`.
Created using the built-in image-generation tool (not the CLI), with transparent background enabled. Used in both desktop clients and their connection dialogs.

Generation prompt:

> Use case: logo-brand. Create one polished, memorable app logo icon for CampusBite, a modern college canteen ordering app. Square composition, centered single symbol, NO text or letters. A warm ivory rounded-square tile containing a bold forest-green stylized C-shaped plate, with a small bite removed on its right edge and a simple fork subtly integrated into the left curve. One tiny fresh lime-green leaf accent near the upper right gives a fresh food feel. Flat clean vector-like geometry, sophisticated balanced spacing, crisp edges, readable at 32px. Forest green #16352B, ivory #F6F7F2, lime #DDEFA3 only. No gradients, no shadows, no mockup, no background scene. Transparent outside the rounded-square ivory tile. Symbol fills about 72 percent of tile. This is the original standalone logo icon to ship inside the existing CampusBite desktop app.
